          Você

          Inteligência da Edie básica

          Sem chave, a Edie entende comandos do dia a dia (agenda, tarefas, Instagram). Com uma chave da API do Claude ela conversa sobre qualquer assunto, entende o que você fala do seu jeito e age por você. Crie a chave em platform.claude.com.

          ⚠ A chave fica salva só neste navegador. Não use este app em computador compartilhado com a chave salva.

          Voz da Edie

          As vozes vêm do seu sistema. No Chrome/Edge as vozes "Google português do Brasil" e "Microsoft Francisca/Thalita (Natural)" são as mais naturais.

          Conectar Instagram

          Precisa ser conta Profissional (Criador ou Empresa). Gere um token de acesso no Meta for Developers (produto "Instagram API com login do Instagram", permissões instagram_business_basic e instagram_business_manage_insights).

          Google Agenda

          Opção 1: importe um arquivo .ics (Google Agenda → Configurações → Importar e exportar → Exportar).

          Opção 2: leitura direta de uma agenda pública com uma chave de API do Google Cloud (Calendar API ativada).

          Seus dados

          Tudo fica salvo neste navegador. Faça backup para levar para outro aparelho.
